# ImgLoupe artwork

![ImgLoupe](../../assets/logo.png)

The Soft Lens mark is a loupe over a tilted picture tile, in evergreen teal
(`#005753`) and warm ivory (`#fdfbf5`).

- `mark.svg`: the mark alone, used in the full logo.
- `icon.svg`: the app icon, the mark in ivory on a rounded teal square.
- `wordmark.svg`: the "ImgLoupe" lettering as paths, so no font is needed.

The build renders these sources into the extension icons (16, 32, 48 and 128
pixels, plus a 512-pixel copy), the README logo (with an ivory backing that
stays legible in light and dark GitHub themes) and the 1280 × 640 GitHub
social-preview image. Edit the SVG sources and rebuild; do not edit `assets/`
directly.
